┌────────────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                         │
└────────────────────────────────────────────────────────────────────────────┘

  Arduino Not Detected:
    ✓ Check USB connections
    ✓ Delete thermal_motion_ports.json
    ✓ Restart application
  
  EEG Triggers Not Working:
    ✓ Run: python utilities\trigger_sender.py
    ✓ Verify COM4 is available
    ✓ Test each trigger (press 1-9)
  
  Audio Not Working:
    ✓ Check Downloads folder has:
      - t0500hz.wav
      - t1000hz.wav
    ✓ System works without audio (non-critical)

┌────────────────────────────────────────────────────────────────────────────┐

    1-4     Select condition
