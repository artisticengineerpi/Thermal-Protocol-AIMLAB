================================================================================
EXTERNAL DEPENDENCIES
================================================================================

Required in Downloads Folder:
  • t0500hz.wav                     500Hz tone (trial start, question)
  • t1000hz.wav                     1000Hz tone (stimulation start)

Required Hardware (USB Connected):
  • Peltier Controller (Arduino)   Auto-detected
  • Motor Controller (Arduino)      Auto-detected
  • EEG Trigger Box (COM4)          Auto-detected in experiment mode

Required Python Packages:
  • pyserial                        pip install pyserial
  • tqdm                            pip install tqdm
  • colorama                        pip install colorama
  • keyboard                        pip install keyboard

================================================================================
EXPERIMENT MODES
================================================================================

1. FULL EXPERIMENT MODE (Recommended for data collection)
   • 160 trials (5 blocks × 32 trials)
   • Latin square counterbalanced design
   • 60-second breaks between blocks
   • EEG triggers enabled
   • Audio cues enabled
   • Browser display on secondary monitor

2. SINGLE TRIAL MODE (Good for testing/practice)
   • Manual condition selection
   • EEG triggers enabled
   • Audio cues enabled
   • Browser display enabled

3. DEBUG MODE (Hardware testing)
   • No triggers
   • No audio
   • No browser display
   • Direct stimulation testing
