AIMLAB -- PROTOCOL AT A GLANCE
=============================

  USB + sleeve power
         |
  Launch PsychoPy -> participant ID -> CONNECTED
         |
  Test cues + each motor + Thermal + Combined
         |
  Calibrate MOTOR PWM and PELTIER LEAD -> Save -> Lock -> Space
         |
  [32 trials] -> [60 s break + Space]  x 4
         |
  [last 32 trials] -> FINISHED: 160 trials saved

DEFAULTS
  Motors 189 PWM | Peltier HOT 183 PWM | Motion 4.0 s
  Lead starts at 980 ms. Adjust 0-2000 ms; motor 0-255 PWM.
  PWM is not temperature. Settings lock when experiment starts.

ONE TRIAL
  [Silent cross: random 1.5 or 2.5 s]
                   |
  [1000 Hz beep + white circle + run A, B, C or D]
                   |
  [All outputs OFF confirmed]
                   |
  [500 Hz beep: 0.15 s; circle remains]
                   |
  [Question + all options -> answer 1-5 -> save]

  1 None | 2 Static heat | 3 Moving vibration | 4 Moving heat
  5 Not sure. No response time limit. No EEG.

LATIN SQUARE
  A = None (5 s)       B = Thermal (5 s)
  C = Vibration (4 s)  D = Combined (lead + 4 s)

               Trials 1-16      Trials 17-32
  Read down:     A B D C           A B D C
                 B C A D           B C A D
                 C D B A           C D B A
                 D A C B           D A C B
  Finish the LEFT column of rows, then the RIGHT column.

  Same 32-trial order in every block:
  [ ] Block 1:   1-32      [ ] Block 2:  33-64
  [ ] Block 3:  65-96      [ ] Block 4:  97-128
  [ ] Block 5: 129-160
  40 trials per condition. Seed changes fixation times only.

COMBINED MOTION
  RUN -> [lead] -> [M1 ----> M2 ----> M3 ----> M4] -> OFF
         Peltier ON ================================= OFF
  Peltier enables 50 ms after RUN; stops with the last motor.
  Motor starts: 0, 0.8, 1.6, 2.4 s after lead.
  Each motor: rise 0.4 s -> steady 0.8 s -> fall 0.4 s.
  SOA (gap between starts) = 0.8 s. Motor envelopes overlap.

CALIBRATION LINK STATUS
  Calibration-only dot: GREEN = fresh Uno replies; RED = otherwise.
  Lost link -> abort attempt -> reconnect + OFF -> PAUSE
  Space repeats the same trial. Aborted attempts are also saved.
  Esc stops outputs and pauses; Q then quits. No on-screen quit button.
  Q quits from pause/calibration/completion.
  Resume Session.bat continues a saved session.

  Link status confirms Uno replies, not physical heating/vibration.
  Wiring and launch details: QUICK-PROTOCOL.txt
  Results: data/<session>/trials.csv

PROTOCOL V2
  Cross and filled white circle: same width/height. No blank phase.
  No connection icon during experiment; monitoring continues.
  Recovery fails after 3 failed cycles and 10 s, or 30 s total.
  Then: stop experiment, save data, show error. Q closes.
  Earlier sessions require the archived app (before-binary-fixation).
